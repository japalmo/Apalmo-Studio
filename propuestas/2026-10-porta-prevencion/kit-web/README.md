# Kit web de PORTA

Todo lo necesario para publicar el artículo de PORTA en la bitácora de apalmo y su lista de espera del piloto.

| Archivo | Para qué |
|---|---|
| `PROMPT-WEB.md` | Prompt para la sesión que trabaja la web (`Apalmo Studio\WEB`) |
| `FICHA.md` | Qué es PORTA, cómo funciona, qué comunicar y qué no (fuente de verdad) |
| `HISTORIA.md` | Motivación, entrevista de AIEP y preguntas que Juan debe responder |
| `medios/MEDIOS.md` | Índice de medios optimizados con texto alternativo y qué no usar |
| `medios/` | Imágenes WebP, renders, cuadros del reel, reel 720p, giro 3D, logos SVG |

Contexto en la carpeta padre: `README.md` (entregables), `PORTA-propuesta.pdf`, `fuente/` (prototipos), `reel/CAPTION.md` (caption de Instagram) y `reel/narracion/` (guion de la voz).
